# 簽名板

在 iPhone 上用手指簽名的網頁工具，畫面固定橫向，像刷卡機的簽名欄。可以開啟 Word (.docx) 檔，在文件上點簽名框就跳出簽名板，簽完簽名自動放進那個位置。

## 功能

- 手指或觸控筆簽名，筆跡隨速度變粗細
- 復原、清除、確認
- 手機直拿時畫面自動轉 90°，橫拿即可簽名
- 輸出簽名 PNG（可選透明背景）
- 開啟 .docx 會顯示整份文件，`{{簽名}}` 的位置變成藍色閃爍的簽名框
- 點簽名框 → 簽名 → 確認，簽名立刻出現在文件上；點已簽的簽名可以重簽
- 全部簽完後「儲存 Word」，用分享選單存檔或傳出
- 所有處理都在手機瀏覽器內完成，檔案不會上傳

## Word 標記

| 寫法 | 效果 |
|---|---|
| `{{簽名}}` | 放入簽名 |
| `{{客戶簽名}}`、`{{經手人簽名}}` | 每個名稱各簽一次，依序簽 |
| `{{日期}}` | 自動填入當天日期（YYYY/MM/DD） |

- 名稱含「簽」或 sign 才會當成簽名欄
- 括號要用半形 `{{ }}`
- 舊版 .doc 請先另存成 .docx
- 簽名最大約 5 × 1.4 公分，等比縮放

## 使用

用 Safari 開啟 GitHub Pages 網址，分享 →「加入主畫面」，就能像 app 一樣使用。第一次開啟後，沒有網路也能簽名。

- 儲存圖片／Word：iPhone 會叫出分享選單，可選「儲存影像」、「儲存到檔案」或直接傳給別人
- Word 功能第一次需要網路載入 JSZip（cdnjs）和 docx-preview（jsDelivr），之後會留在離線快取裡
- 文件畫面是預覽，字型和行距可能和 Word 略有不同；存出的 Word 檔只改動簽名和日期標記

## 檔案

- `index.html`：主程式
- `manifest.webmanifest`、`apple-touch-icon.png`、`icon-512.png`：加入主畫面用
- `sw.js`：離線快取，改版時把 `CACHE` 版本號 +1
